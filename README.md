# Trazo a Mermaid

Dibuja diagramas con el lápiz de la tablet y obtén el código [Mermaid](https://mermaid.js.org/) en vivo.

- Rectángulo, rombo o elipse dibujados a mano → nodos del tipo de diagrama elegido.
- Línea de una forma a otra → conexión.
- Toque sobre un elemento → editar su texto o borrarlo.
- Lápiz dibuja, dedo mueve.

## Uso
Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

y abre `http://localhost:8000` (o `http://<ip-del-pc>:8000` desde la tablet en la misma red).
